## Цель работы

1. Познакомиться с понятием цикла и его видами.
2. Научиться использовать циклы `while` и `for` в Python.
3. Изучить операторы `break`, `continue`, `pass` и их применение.
4. Освоить вложенные циклы и табуляцию функций.
5. Применить полученные знания для решения практических задач на итерации.
6. Отработать навыки работы с Git: коммиты, ветвление, push.

## Как запустить

Нужен Python 3.10 и выше. Все программы запускаются из корня репозитория:

```bash
python Лабы/лаба5/лаба1.py
python Лабы/лаба5/лаба2.py
python Лабы/лаба5/sr1.py
```
